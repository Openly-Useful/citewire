# citewire.org

Dependency-free static landing page for citewire Community. It uses the
Openly Useful design-system family tokens and self-hosted OFL fonts, with a
distinct Citewire wire-and-source identity.

Preview locally from this directory:

```sh
python3 -m http.server 4173
```

The canonical domain is `https://citewire.org`. This repository does not
authorize a deployment or DNS change. Deploy only after the owner approves the
exact Vercel project, Git repository, DNS records, and production verification
sequence.

The site is excluded from the npm package by the root `files` allowlist.
