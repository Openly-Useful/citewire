# WS-013 — Versioned public MCP contract ADR

## Objective

Design, but do not implement, a backward-compatible Community MCP contract for
discovery, metadata, explanations, health, and resources.

## Priority, status, and dependencies

- Priority: P1.
- Status: planned, design-only.
- Dependencies: WS-002.

## Current state

Community currently exposes news.list, news.get, news.topics, news.about,
optional provider tools, stdio, and stateless HTTP. Resources, inclusion tiers,
reason tags, and decision traces are absent.

## Exclusive ownership

- docs/platform-contract.md
- docs/adr-public-mcp-contract-v1.md

Runtime, test, package, registry, deployment, Studio, plugins,
accounts/identity, persistence, scheduling, credential storage, Cloud
operations, and Karaya state are excluded.

## Binary definition of done

An independently reviewed ADR defines versioning, capability discovery,
schemas, resources, attribution/canonical/rights/inclusion/health fields,
errors, compatibility, fixture specifications, stdio/direct-HTTP smoke
specifications, and explicit exclusion of Karaya state. No runtime, test,
package, registry, or deployment mutation occurs.

WS-017 is the sole later serialized runtime implementation, after WS-004 and
explicit owner approval. WS-013 does not authorize implementation work.

## Checks

- Read-only inventory current news.*, RPC, HTTP, stdio, and committed tests.
- Write schema/fixture compatibility matrix and later implementation smoke
  specification.
- Independently review Community boundary against Karaya and Cloud.

## Artifact and rollback

The artifact is docs/adr-public-mcp-contract-v1.md. Revert ADR proposal only
and preserve current protocol behavior.

## Escalation

Stop for breaking contract, Karaya-specific field, rights ambiguity, provider
activation, publication, registry action, secret, or deployment.
