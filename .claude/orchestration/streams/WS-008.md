repository, candidate, and live website gates complete.

## Binary definition of done

- Each irreversible step has separate exact owner approval.
- Approved main is tagged once.
- No-publication preflight runs with publication toggles false.
- Every public package, release, MCP, support/security, homepage, and
  documentation URL resolves to the independently verified live HTTPS
  destination before irreversible publication.
- npm version, integrity, provenance, MCP identity, and MCP Registry record
  are independently verified.
- GitHub release follows only after correct public records and healthy
  canonical website.

## Checks

- Run Community suite, release check, package dry run, and diff check.
- Run manual no-publication workflow preflight from exact approved tag.
- After approval, verify npm, provenance, registry, and public URLs.
- Confirm Cloud transition starts only after immutable published evidence.

## Artifact and rollback

The artifact is docs/distribution.md and release evidence. Before publication,
revert focused release changes. After publication, use only owner-approved
deprecation or fixed-patch procedure; never overwrite or retag.
